## Helping Hand (Frontend)

**Helping Hand** is an emergency assistance platform where users can send SOS alerts and nearby volunteers can respond to help.

---
## Description

This is  the frontend service for the app called **Helping Hand** developed in react JS and leaflet.
The frontend insight:

- map rendered with **leaflet** and map is provided by **open street map** & **CartoCDN**
- nearby place is fetched using **nominatim**

## Tech stack

- React JS
- Leaflet


## Project structure
**src** folder is the parent folder for the components.
- **component** folder contains  all the view componenet 
- **App.jsx** contains all the component and handles conditional rendering
- **main.jsx** contains final component to be rendered on the html page
